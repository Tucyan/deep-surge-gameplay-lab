# 深涌 · 玩法实验与策划工具

独立 JavaScript 玩法实验。主界面包括首页、航行和战斗；策划工具编辑内容数据、校验引用、导入导出配置。

## 启动

需要 Node.js 22 或更新版本，无需安装依赖。双击 `启动实验.cmd`，或在本目录执行 `npm start`。

- 游戏：`http://127.0.0.1:5080/`
- 策划工具：`http://127.0.0.1:5080/editor/`

## 策划工作流程

1. 从左侧选内容分类，选择已有条目，或新建/复制。
2. 填写名字、说明、数值；通过选择器添加效果、材料、前置科技和奖励。
3. 查看校验提示。引用不存在、数值越界或科技依赖成环时无法应用。
4. 应用到试玩，进入游戏开启新航行。不同配置分别保存进度。
5. 导出配置交给其他人。对方可在策划工具或游戏“玩法配置”中导入。

浏览器草稿、已应用配置、航行记录是不同文件。草稿允许保留未完成的内容；导出和应用要求配置合法。导入失败保留原稿。浏览器数据只在当前浏览器/网站有效，跨设备请导出备份。

公开编辑器不会把个人草稿直接发布到服务器。发布新默认玩法时，将合法导出文件替换 `config/default.json`，检查通过后提交推送，再运行一键更新。

## 内容与规则

| 文件 | 用途 |
| --- | --- |
| `src/content/cards.js` | 卡牌与涌泉资源池 |
| `src/content/nodes.js` | 节点、选项、怪物、商店、日记、结局 |
| `src/content/equipment.js` | 设备与配方 |
| `src/content/rules.js` | 初始值、出身、Buff、航行消耗和结算顺序 |
| `src/content/relics.js` | 藏品、局外商店、科技树 |
| `src/config/validation.js` | 配置形状、数值、引用和依赖校验 |
| `src/core/` | 命令、规则执行、战斗、生存、成长 |
| `src/editor/` | 策划表单与编辑流程 |
| `config/default.json` | 网站默认使用的玩法配置 |
| `玩法重制/` | 玩法及接口草稿 |

可新建核心已支持的卡牌、普通节点、自动生产/战斗供给设备、配方、Buff、藏品、出身和科技。原生灯、治疗、升级、兑换、结局判定等机制的行为类型仍由核心实现；编辑器提示相关限制。配置不会执行脚本。

`npm run export:default` 从源码内容重新生成发布配置，会覆盖 `config/default.json`。正常策划工作优先使用编辑器导出。

## 验证与发布

执行 `npm run check` 和 `npm test`。部署方法、一键更新和两个在线入口见 [DEPLOYMENT.md](DEPLOYMENT.md)。当前玩法参数属于实验方案，完整机制与待定内容以 `玩法重制` 中的文档为准。
