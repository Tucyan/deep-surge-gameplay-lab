# 实验参数

更新：2026-10-07。以下为当前 `gameplay-experiment-v5` 默认定义，可通过策划配置调整；已实现不代表最终平衡已确认。个人浏览器配置可能覆盖发布值，报告应记录实际配置指纹。

- 固定起手出拳、木头、塑料、废铁各1；首次导航前自动领取三张涌泉，因此空白档案共七张。局外奖励可增加起手；木筏4格。
- `CONFIG.layers` 默认仅一层，种子决定10～15站，每层末站固定首领。层定义可覆盖航程范围，核心已支持跨层，双层仅测试配置验证，没有第二层正式内容。
- 涌泉先于导航，每轮一次，漂流丰收多1张；确认启航不再给牌。节点普通池为本层普通航程的2倍，允许重复，实际到达才消耗一份，未选保留，已选降权。
- 基地和战斗分别刷新3AP；手牌上限10。
- 战斗及战后行动允许超限，战斗回合末不弃牌，仅主动结束航行时整理。该行为沿用 [历史 v4](商店与轮末弃牌.md)。
- 基地AP耗尽不自动结束航行，仍可使用0AP生存牌或免费操作；点击“结束本次航行”后才结算并进入弃牌。
- 每航行轮消耗饱食30、水分30、精神15；战斗不推进此时钟。
- 食水牌各恢复40；包扎包消耗1 AP与布条1，治疗8/12/16；Ⅰ级食水设备每两轮产1，Ⅱ级每轮产1，Ⅲ级每轮产2。燃灯消耗后、生存检查前恢复SAN15/20/25。
- 免费休整四选一：生命+15、食水/SAN各+40并给休整余裕；免费升级一件合法设备；免费附魔一张合法牌；离开。没有材料/AP/HP/SAN/燃料费用，不消耗目标。
- 合成与安装分别收费；自动生产并领取；设备二合一升级，最高3级。
- 扩建消耗2木头、1AP；负面手牌留手造成损失，花战斗AP清除。
- 节点完成数用于局外积分；科技与局外商店影响下一局。

新内容只能组合核心已支持的效果。特殊机制仍需调整规则代码。

## v5 环境、价格与藏品

| 参数 | 默认值与限制 |
| --- | --- |
| 环境抽取 | 首轮及层末站跳过；其余轮25%触发，触发后75%负面，最多3个、负面最多2个 |
| 迷雾 | Ⅰ级35%固定遮详情、Ⅱ级只显示类型，各2航行；Ⅲ级全未知1航行，仅风险事件，不能与混乱共存 |
| 血月 | 直接生命攻击+1、非Boss战斗胜利贝币+1，2航行；不加中毒/污染等额外伤害 |
| 混乱 | 25%偏航，2航行；木头1或定向骨针额度可免本次偏航，Boss免疫 |
| 侦察 | SAN8且支付后至少1，或潮纹镜片1次机会；揭示一个固定候选 |
| 顺流/丰收 | 顺流食水航耗各少5、2航行；丰收下一次涌泉多1张，领完移除 |
| 逆流 | 首次制造/安装额外1 AP、2航行；已实现，默认随机池关闭 |
| 祭坛 | 奖励最多2件固定普通藏品；随机手牌3份、HP8或立即脱落1个合法外围格，三种支付选一；可免费离开 |
| 水母记忆交易 | 塑料1、SAN10、1 AP；SAN>80确定藏品，否则60%，失败贝币1 |
| 潮纹镜片 | 获得1次机会，用后2次结算恢复，最多1次 |
| 定向骨针/记名绳结 | 每层各2次，保护牌只保护一份实体单位，其他单位仍足额支付 |
| 余烬灯芯/缝潮针 | 实际燃灯每轮额外SAN5；首次直接修理木头少1，仍需AP |
| 指环/罗盘/契印 | 事件投入3份非货币牌后资源1；航耗前容量≤5食水各少5；主动SAN事件贝币1且基础SAN航耗额外5。相关奖励每轮至多一次 |

节点获得环境从下一轮生效，随机轮初环境当轮生效；状态剩余表示实际覆盖航行次数。主动HP/SAN价格必须支付后至少剩1，不吃愚者减免，不由珍珠垫付。待领取藏品可拒绝，但不重抽，处理前其他行动被阻止。更多范围与例外见 [玩法](玩法.md)。
