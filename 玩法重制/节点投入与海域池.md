# 节点投入与海域池试测 v3

日期：2026-10-05。仅适用于本目录独立玩法实验，不修改 water-era 首版规则。用户提出增加事件手牌消耗，并指定本层种子生成可重复节点池，只有选择才消耗。物资数量、AP和权重系数均为本次试测参数。

## 本层节点池

- 先确定航程，再有放回抽取“2 ×（航程 − 1）”份普通节点，形成 nodePool。同类型可有多份，例如 [drift, camp, drift, battle, …]。初始池至少含一个非战斗节点，不承诺每轮都有休整或补给。
- 每轮抽出至多三个不同类型的候选。剩余池有非战斗类型时，保留一个非战斗候选；其余从剩余类型抽取。同屏不重复类型，只剩一或两种时按实际类型数显示。
- 类型权重 = 剩余份数 / (1 + 3 × 本局已选次数)。上一次选中类型再乘0.25。降权不禁止重复，不改变池内份数。
- SubmitVoyage成功才从池中删除选中类型的一份，增加nodeVisits并更新lastNodeId。未选份数不变；查看、预览、失败命令不消耗实际池或随机状态。
- 确认启航后即消耗，即使节点内选择离开或战斗撤退，也不放回。历史仅属于本局，不读取局外完成数量。
- 最后一站固定Boss，不占普通池。普通航程走完，池仍剩“航程 − 1”份，未选的事件可整层避开；无中途补池。CONFIG.nodePoolMultiplier 默认2，策划范围为1～10。

## 事件投入

选项新增可编辑的 cardCosts: {卡牌定义ID: 数量}，原cost仍为基地AP。省略cardCosts表示无物资费用。费用仅支持资源、生存牌及贝币，不允许提交污染牌、回牌攻击或已安装设备。

| 节点选项 | 实际投入 | 收益 |
|---|---|---|
| 漂浮物：编网打捞 | 绳索1、布条1、1 AP | 木头2、塑料1 |
| 漂浮物：金属货箱 | 木头2、塑料1、1 AP | 废铁2、绳索1 |
| 漂浮物：密封补给箱 | 废铁1、绳索1、布条1、1 AP | 淡水1、食用植物1 |
| 休整：包扎补给 | 布条2、1 AP | 生命+15，饱食/水分/精神各+40、休整余裕 |
| 休整：委托升级 | 废铁2、绳索1、1 AP | 一件可用未满级已安装设备升一级 |
| 休整：供奉附魔 | 布条2、怪物尸体1、1 AP | 一张战斗/生存/行动牌赋予回牌或瞬发 |
| 水母：资源转换 | 塑料1、布条1、1 AP，再提交剩余的一份基础资源 | 随机另一种基础资源1 |
| 水母：献血 | 布条1、生命5，无AP费用 | 50%普通藏品，50%无所得；致死停止随机与奖励 |
| 风暴：系绳打捞 | 绳索1、木头1、1 AP | 外围一格受损，木头1、废铁2 |
| 风暴：浮架回收 | 废铁1、绳索1、布条1、1 AP | 淡水1、食用植物1、精神+20，无额外筏损 |

普通节点保留无费用、无奖励的离开选项。商店交易及战斗机制不变。材料回收仍允许小幅净增物资；补给、休整、升级、附魔承担消耗，不能声称所有事件都净减少手牌。

先扣完整费用，再处理特殊目标和奖励；任一步失败，会话事务完整恢复牌、AP、随机与节点状态。费用按手牌顺序消耗对应定义的指定数量，支持叠放。投入不算打出，回牌附魔不返还。收益不能倒付费用，重复选项不能重复领奖。

## 配置、存档和界面

策划工具可在节点选项添加“节点投入（实际消耗手牌）”，发布配置config/default.json同步。界面从费用生成投入、持有量、缺料原因；物资或AP不足禁用选择。特殊目标仍需选手牌或设备，由核心验证。

内容契约升为gameplay-experiment-v3，schema仍为1，随机算法仍为xorshift32-v1。保存剩余池、选择次数、上一节点和随机状态。v1/v2航行不能作为v3继续；浏览器按版本隔离记录，旧记录不删除。旧自定义配置需基于v3默认配置更新内容版本、补齐nodePoolMultiplier并重新校验，不自动覆盖个人配置。

验证见 [v3平衡报告](../evidence/balance-review-v3.md)。旧v2结果保留于 [旧验证记录](../evidence/node-economy-v2-verification.md)。
