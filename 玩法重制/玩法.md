# 玩法 · 当前 v5

更新：2026-10-07。适用于独立「玩法实验」`gameplay-experiment-v5`，不替换 `water-era` 规则。以下为已接入的运行行为，数值仍属程序试测。文末历史讨论及 v2～v4 记录保留原背景，不作为当前规则。

## 当前航行流程与层

`CONFIG.layers` 配置层 ID、名称、末站首领和可选长度范围，种子在开局确定各层长度。当前默认一层10～15站，双层仅通过测试配置验证衔接，没有第二层正式内容。核心保存当前层航次与全局航次，战斗回合不推进二者。

每轮流程：自动涌泉 → 导航 → 确认启航 → 基地准备 → 节点/战斗 → 基地收尾 → 消耗、燃灯、生存检查、筏格老化、生产、状态计时 → 弃牌。弃牌通过才开始下一轮。首次同样先领涌泉：空白档案固定出拳、木头、塑料、废铁各1，加三张随机基础资源，共七张；漂流丰收多1张，领取后移除。本轮领取标记随存档保存，启航不再发牌。

基地 AP 启航时设为上限，默认3；战斗每回合独立刷新3，战后不刷新基地 AP。节点完成或 AP 归零不自动结束航行，仍可使用0 AP牌；主动结束才结算。导航只允许已支持的侦察与固定航向，不开放制造、安装和生存出牌。轮内、战斗及战后可超限，仅轮末整理，前端容量满足时可自动提交确认。

每层末站固定首领，免于迷雾和偏航，可承受已生效血月。胜利后先结算与弃牌，再进入下一层，保留当前生命等数值、手牌、木筏、设备、等级及本局藏品，重建本层池和访问历史；末层胜利结束本局。未击败末站首领则得到撤离结局，不能视为击败。

## 当前节点与支付

正常候选按已领取涌泉后的真实库存显示费用、目标、可用性与概率，不再提示启航后补给。漂浮物和风暴有固定变体，选项布局不统一套三档模板；当前节点实例优先于静态定义，查看或取消不重抽。

休整四选一全部免费：生命恢复15、食水与 SAN 各40并获得休整余裕；升级一件完好格上未满级的已安装设备；为合法战斗/生存/行动牌附魔；直接离开。没有 AP、材料、燃料、HP 或 SAN 费用，目标不消耗。无目标只禁用对应升级或附魔项；满值允许恢复但不超过上限。

水母基础兑换支付1 AP和一份基础资源，无额外媒介；记忆交易支付塑料1、SAN10、1 AP，提交前 SAN>80 确定获得藏品，否则60%，失败贝币1。主动 SAN/HP 价格完整支付且至少剩1，愚者减损与珍珠保护不能代付。保留的水母献血仍为布条1、事件生命损失5及50%藏品，采用该分支原有败亡处理，不与祭坛HP价格混同。

祭坛固定展示最多两件未持有普通藏品，先选奖励，再选择随机失去3份合格手牌、支付HP8、随机立即脱落一个合法外围格，或免费离开。手牌按实体单位等概率、不放回：资源、生存、待安装设备、普通行动牌可损失；出拳、货币、临时战斗牌、污染、已安装设备及独立工具排除。投入不触发回牌。脱落同时毁掉设备，不能修补，不能毁最后一格或使剩余格断开。确认前公开费用、合法对象与可能损失。普通藏品全部持有时祭坛改为物资事件。

随机事件和遗迹的藏品奖励进入待领取状态，先查看效果与代价，再领取或拒绝，处理前不能继续行动；拒绝不重抽。祭坛是在支付前选定奖励，不在支付后拒绝退款。

## 当前环境与导航

首轮与每层末站不新抽环境；其余轮涌泉前25%触发，触发后75%负面、25%正面，从合法加权池抽取。最多3个环境状态，负面最多2个。当前随机池有迷雾Ⅰ/Ⅱ、血月、混乱、顺流、漂流丰收；迷雾Ⅲ来自明示风险事件，逆流已有处理但默认随机池关闭。

| 状态 | 当前行为 |
| --- | --- |
| 迷雾Ⅰ | 固定判定35%遮蔽选项、费用、奖励，保留名字和类型；2次航行 |
| 迷雾Ⅱ | 隐藏名字、敌人、选项，只保留类型；2次航行 |
| 迷雾Ⅲ | 名字、类型、选项均隐藏；1次航行。池内有非战斗路径时保留可辨认候选，不额外补池 |
| 血月 | 敌方直接生命攻击+1，非Boss战斗胜利额外贝币1；不放大中毒、污染或额外深潜伤害；2次航行 |
| 混乱 | 25%偏航至本次其他候选，只消耗实际到达节点一份，计划节点保留；2次航行 |
| 顺流 | 食水航耗各少5，2次航行 |
| 漂流丰收 | 下一次涌泉多1份，领取后移除 |
| 逆流 | 每轮首次制造或安装多1 AP，2次航行；默认随机池未启用 |

节点获得的环境状态下一轮生效，不突然遮蔽当前候选；激活状态覆盖本轮完整流程，轮末才扣次数。战斗不推进航行状态。迷雾Ⅲ与混乱不共存，同状态刷新期限而非叠数值。侦察支付 SAN8 或潮纹镜片机会，揭示一个候选；混乱时可支付木头1或定向骨针额度固定本次航向。灯塔导引要求完好燃灯，下一轮揭示全部候选并使偏航概率减15个百分点。

## 当前生存、木筏与藏品

基础食水航耗各30、SAN15，食水牌各恢复40。燃灯在消耗后、生存检查前恢复SAN15/20/25，破损格设备不燃烧；界面按当前条件预测结算后SAN。饥渴伤害合计最多4，生产在生存检查后，不能倒救本轮饥渴。滤水器与土盆Ⅰ级每两轮产1、Ⅱ级每轮产1、Ⅲ级每轮产2；包扎包1 AP和布条1，治疗8/12/16。制造与安装各收费，普通二合一升级与免费休整升级是不同途径。

| 新普通藏品 | 行为与边界 |
| --- | --- |
| 余烬灯芯 | 实际燃灯时每轮额外SAN5，多灯只触发一次 |
| 潮纹镜片 | 获得一次侦察，使用后两次完整航行恢复，最多存1次 |
| 定向骨针 | 每层2次固定航向 |
| 缝潮针 | 每轮首次直接修理少耗木头1，仍需AP，不减扩建和修补包制造费 |
| 记名绳结 | 每层2次保护一份随机失牌对象，其他单位仍须足额支付 |
| 拾荒者指环 | 事件累计实际投入3份非货币手牌后回收资源1，每轮一次，不计制造、燃灯、交易或弃牌 |
| 空腹罗盘 | 航耗前容量≤5时食水航耗各少5，可与顺流叠加，后续生产/弃牌不改判定 |
| 深潮契印 | 主动SAN事件完成后贝币1，每轮一次；基础SAN航耗额外5，导航侦察不触发 |

八件新藏品均为本局普通藏品，不转为永久成长。次数、充能和触发航次随存档保存，读档不补额度。原珍稀藏品、出身、科技、商店、战斗牌及局外系统仍读取当前内容定义。

# 历史玩法预案（讨论依据）

以下保留《10.4修改日志》时期的设计草稿及历史试测背景，不作为 v5 当前运行规则。旧数值仍属当时暂定；历史未完成及冲突项见[玩法待完善](玩法待完善.md)。

## 总览

分为局内航行与局外养成。木筏作为独立基地，通过生产资源、提供增益和战斗牌支援战斗。每层由种子决定进行10～15次行进，战斗回合不计入行进次数。

流程：导航 → 涌泉补给 → 基地准备 → 节点/战斗 → 基地收尾 → 生存、生产与弃牌结算。涌泉沿用每轮免费三张，牌池改为仅资源牌。

## AP系统

- 沿用基地每航行轮3 AP，准备与收尾共用；战斗独立，每回合3 AP，结束战斗不刷新基地AP。
- 生存牌均为0 AP；制作、安装、拆除分别收费。燃料投入灯中为0 AP。
- AP不跨轮累积；0 AP不等于保留卡牌，回牌需有对应效果。

## 木筏系统

- 初始2×2，每格一件设备。设备须安装在木筏上才生效；自动生产、自动将产物加入手牌，不扣AP，无设备仓储。
- **建造**：制造得到设备手牌，非战斗时使用该牌安装到完好空格；安装1 AP沿用旧预案。
- **扩建**：直接消耗木头牌×2与1 AP增加一格，替代扩建包；默认扩建上限3×3，局外购买后可提高至4×4。
- **拆除**：沿用拆除牌，消耗该牌与1 AP，释放占格，返还建造配方中自选的一份基础材料；升级投入不返还。
- **升级**：两个同类、同等级设备合成为一个更高等级设备，增强效果；具体操作及AP费用暂不定。
- 沿用环境造成的筏格破损、停用、老化和脱落；战斗不直接攻击木筏设备。

| 设备 | 明确用途/效果 |
|---|---|
| 灯 | 燃烧时恢复精神值15；木头可烧1节点，怪物尸体可烧3节点，投料0 AP |
| 滤水器 | Ⅰ级每两航行轮生成淡水×1；Ⅱ级每轮生成淡水×1 |
| 土盆 | 产出可食用植物 |
| 包扎包 | 占用木筏面积，花1 AP恢复HP |
| 弓弩 | 沿用战斗每回合生成射箭×1；Ⅱ级每组最多2张箭占1手牌容量，Ⅲ级每组最多3张占1容量 |

上述四种生存设备作为新版方向；捕捞网、集雨器的旧配方与数值暂撤出。土盆产量、治疗量、燃灯结算等未写清的细节不补写。

## 战斗系统

木筏与战斗分离，玩家使用战斗牌行动，设备提供牌或增益。胜利获得局内货币、怪物尸体和角色经验。出拳消耗1 AP、造成1伤害，具有回牌效果，其余常规战斗牌由设备产出。

层底Boss可施加Debuff或塞入负面手牌；负面牌每在手中停留一回合就造成对应惩罚，需要花额外AP打出。具体费用、惩罚与清除规则待完善。

日志明确暂缓战斗重做；旧弱点、战术补给、撤退与战后清牌方案的适配另列待完善，不视为新版已定规则。

## 手牌

初始共4张，包含1张出拳，其余初始牌构成待确认。主要分资源牌、生存牌、战斗牌；设备牌、拆除牌仍保留操作用途。资源改为手牌，不再使用旧预案的无限独立物资栏。基础手牌上限10、航行轮末弃超限牌暂沿用。

| 手牌 | 用途 | 使用AP | 来源 |
|---|---|---|---|
| 资源牌：木头、废铁、塑料等 | 制造；木头也可扩建、燃灯 | 制作另计；投料0 | 涌泉等 |
| 怪物尸体 | 燃灯3节点、与商人交易 | 投料0 | 战斗胜利 |
| 货币牌 | 局内交易；数量≥1合计占1手牌容量 | 交易费用未定 | 战斗等 |
| 生存牌 | 直接恢复饱食、水分或精神值，均有瞬发效果 | 0 | 生存设备 |
| 出拳 | 伤害1，具有回牌效果 | 1 | 初始固定一张 |
| 射箭等战斗牌 | 对敌行动，设备升级可赋予堆叠效果 | 除出拳外待定 | 战斗设备 |
| 设备牌 | 安装后提供设备效果 | 1（沿用） | 制造、商人 |
| 拆除牌 | 拆除设备并回收部分材料 | 1（沿用） | 制造 |
| 负面牌 | 留手每回合造成惩罚，打出需额外AP | 待定 | Boss污染 |

瞬发表示打出0 AP；回牌表示部分牌打出或弃置后返回手牌；堆叠表示多张牌按规定数量共占容量。回牌、瞬发可由附魔获得，具体附魔规则待完善。删除电学相关手牌，以及逆流桨、折叠锚、听潮筒。

## 合成制造配方

制造产物先进入手牌，设备须另行安装。新设备配方尚未提供；仅保留未与日志冲突的旧稿暂定配方。

| 成品 | 工具 | 材料 | 制作AP |
|---|---|---|---|
| 弓弩牌（沿用旧轻弩配方） | 手工工具 | 废铁+绳索+木头 | 1 |
| 修补包 | 手工工具 | 木头+废铁 | 1 |
| 拆除牌 | 手工工具 | 木头+废铁 | 1 |

木筏扩建直接花木头×2与1 AP，不制造扩建包。灯、滤水器、土盆、包扎包等配方留待补充；电学与导航道具配方删除，旧稿其余道具的去留另列待完善。

## 生存系统

按本次日志更新：每次行进饱食−30、水分−30、精神值−15；食物恢复饱食25，淡水恢复水分25，燃灯恢复精神值15。精神值在日志中称sun、旧稿称SAN，最终命名和燃灯结算时点待确认。

初始饱食/水分各40及饥渴伤害暂沿用：饥饿扣生命2、缺水扣3，合计最多4；生命归零失败。既有轮末顺序为生存消耗与败亡、筏格老化、鲜鱼腐坏、设备生产、弃牌。精神值归零后果与日志有冲突，暂不改写。

## 藏品与Buff

藏品可提供增益、Debuff，间接影响玩法或引导结局。普通藏品通过局内商人交易获得，仅本局有效；珍稀藏品通过达成结局或要求获得，效果永久保留。

“记忆的回响”（唱片外形）：累计完成50个节点获得，AP上限+1。其余未完成藏品列入待完善。Buff包括正向与负面效果，持续、叠加和移除规则尚未定义。

## 局外系统

主页入口：开始新游戏、继续游戏、海怪商店、调查手记、退出游戏。“继续游戏”需要真实存档功能，此处仅记录设计。

调查手记包含怪物、藏品、手牌图鉴，以及日记、结局画廊。每局结算按经过节点数发放局外点数，每节点1点，替代此前按评分发点的设想。本文暂沿用“涌潮点”名称，日志称“涌泉点”，命名待统一。

局外商店用点数兑换藏品或增强角色能力。已记录的购买效果：木筏扩建上限提高至4×4、开局货币+3、商人价格>1时费用−1、AP上限+1、手牌上限+1或+2。售价、持续范围与叠加限制待补齐；“各项生存数值+5”因初始值/上限未区分，暂不合并。

科技树保留此前设想：点亮节点可提供永久收益或解锁新内容；与局外商店的分工及消耗尚待设计。
