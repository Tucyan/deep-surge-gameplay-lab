# 玩法预案草稿

依据《10.4修改日志》合并明确内容；仅为设计草稿，未实现、未测试。日志未改动的规则沿用旧预案，旧数值仍属暂定。未完成及冲突项见[玩法待完善](玩法待完善.md)。

## 总览

分为局内航行与局外养成。木筏作为独立基地，通过生产资源、提供增益和战斗牌支援战斗。每层由种子决定进行10～15次行进，战斗回合不计入行进次数。

流程：导航 → 涌泉补给 → 基地准备 → 节点/战斗 → 基地收尾 → 生存、生产与弃牌结算。涌泉沿用每轮免费三张，牌池改为仅资源牌。

## AP系统

- 沿用基地每航行轮3 AP，准备与收尾共用；战斗独立，每回合3 AP，结束战斗不刷新基地AP。
- 生存牌均为0 AP；制作、安装、拆除分别收费。燃料投入灯中为0 AP。
- AP不跨轮累积；0 AP不等于保留卡牌，回牌需有对应效果。

## 木筏系统

- 初始2×2，每格一件设备。设备须安装在木筏上才生效；自动生产、自动将产物加入手牌，不扣AP，无设备仓储。
- **建造**：制造得到设备手牌，非战斗时使用该牌安装到完好空格；安装1 AP沿用旧预案。
- **扩建**：直接消耗木头牌×2与1 AP增加一格，替代扩建包；默认扩建上限3×3，局外购买后可提高至4×4。
- **拆除**：沿用拆除牌，消耗该牌与1 AP，释放占格，返还建造配方中自选的一份基础材料；升级投入不返还。
- **升级**：两个同类、同等级设备合成为一个更高等级设备，增强效果；具体操作及AP费用暂不定。
- 沿用环境造成的筏格破损、停用、老化和脱落；战斗不直接攻击木筏设备。

| 设备 | 明确用途/效果 |
|---|---|
| 灯 | 燃烧时恢复精神值15；木头可烧1节点，怪物尸体可烧3节点，投料0 AP |
| 滤水器 | Ⅰ级每两航行轮生成淡水×1；Ⅱ级每轮生成淡水×1 |
| 土盆 | 产出可食用植物 |
| 包扎包 | 占用木筏面积，花1 AP恢复HP |
| 弓弩 | 沿用战斗每回合生成射箭×1；Ⅱ级每组最多2张箭占1手牌容量，Ⅲ级每组最多3张占1容量 |

上述四种生存设备作为新版方向；捕捞网、集雨器的旧配方与数值暂撤出。土盆产量、治疗量、燃灯结算等未写清的细节不补写。

## 战斗系统

木筏与战斗分离，玩家使用战斗牌行动，设备提供牌或增益。胜利获得局内货币、怪物尸体和角色经验。出拳消耗1 AP、造成1伤害，具有回牌效果，其余常规战斗牌由设备产出。

层底Boss可施加Debuff或塞入负面手牌；负面牌每在手中停留一回合就造成对应惩罚，需要花额外AP打出。具体费用、惩罚与清除规则待完善。

日志明确暂缓战斗重做；旧弱点、战术补给、撤退与战后清牌方案的适配另列待完善，不视为新版已定规则。

## 手牌

初始共4张，包含1张出拳，其余初始牌构成待确认。主要分资源牌、生存牌、战斗牌；设备牌、拆除牌仍保留操作用途。资源改为手牌，不再使用旧预案的无限独立物资栏。基础手牌上限10、航行轮末弃超限牌暂沿用。

| 手牌 | 用途 | 使用AP | 来源 |
|---|---|---|---|
| 资源牌：木头、废铁、塑料等 | 制造；木头也可扩建、燃灯 | 制作另计；投料0 | 涌泉等 |
| 怪物尸体 | 燃灯3节点、与商人交易 | 投料0 | 战斗胜利 |
| 货币牌 | 局内交易；数量≥1合计占1手牌容量 | 交易费用未定 | 战斗等 |
| 生存牌 | 直接恢复饱食、水分或精神值，均有瞬发效果 | 0 | 生存设备 |
| 出拳 | 伤害1，具有回牌效果 | 1 | 初始固定一张 |
| 射箭等战斗牌 | 对敌行动，设备升级可赋予堆叠效果 | 除出拳外待定 | 战斗设备 |
| 设备牌 | 安装后提供设备效果 | 1（沿用） | 制造、商人 |
| 拆除牌 | 拆除设备并回收部分材料 | 1（沿用） | 制造 |
| 负面牌 | 留手每回合造成惩罚，打出需额外AP | 待定 | Boss污染 |

瞬发表示打出0 AP；回牌表示部分牌打出或弃置后返回手牌；堆叠表示多张牌按规定数量共占容量。回牌、瞬发可由附魔获得，具体附魔规则待完善。删除电学相关手牌，以及逆流桨、折叠锚、听潮筒。

|---|---|---|---|

## 生存系统

按本次日志更新：每次行进饱食−30、水分−30、精神值−15；食物恢复饱食25，淡水恢复水分25，燃灯恢复精神值15。精神值在日志中称sun、旧稿称SAN，最终命名和燃灯结算时点待确认。

初始饱食/水分各40及饥渴伤害暂沿用：饥饿扣生命2、缺水扣3，合计最多4；生命归零失败。既有轮末顺序为生存消耗与败亡、筏格老化、鲜鱼腐坏、设备生产、弃牌。精神值归零后果与日志有冲突，暂不改写。

## 藏品与Buff

藏品可提供增益、Debuff，间接影响玩法或引导结局。普通藏品通过局内商人交易获得，仅本局有效；珍稀藏品通过达成结局或要求获得，效果永久保留。

“记忆的回响”（唱片外形）：累计完成50个节点获得，AP上限+1。其余未完成藏品列入待完善。Buff包括正向与负面效果，持续、叠加和移除规则尚未定义。

## 局外系统

主页入口：开始新游戏、继续游戏、海怪商店、调查手记、退出游戏。“继续游戏”需要真实存档功能，此处仅记录设计。

调查手记包含怪物、藏品、手牌图鉴，以及日记、结局画廊。每局结算按经过节点数发放局外点数，每节点1点，替代此前按评分发点的设想。本文暂沿用“涌潮点”名称，日志称“涌泉点”，命名待统一。

局外商店用点数兑换藏品或增强角色能力。已记录的购买效果：木筏扩建上限提高至4×4、开局货币+3、商人价格>1时费用−1、AP上限+1、手牌上限+1或+2。售价、持续范围与叠加限制待补齐；“各项生存数值+5”因初始值/上限未区分，暂不合并。

科技树保留此前设想：点亮节点可提供永久收益或解锁新内容；与局外商店的分工及消耗尚待设计。
